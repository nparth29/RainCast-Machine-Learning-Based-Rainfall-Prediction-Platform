# RainCast Frontend (React + three.js)

This folder contains the **frontend dashboard** for the RainCast project.  
It visualizes rainfall predictions generated by the Flask backend using an interactive 3D UI.

---

## Purpose of the frontend
- Display rainfall predictions returned by the backend API
- Compare outputs of **RandomForest** and **XGBoost** models
- Provide both **city-based prediction** and **manual input mode**
- Present results using a **custom three.js scene** instead of a static UI

---

## Tech stack
- **React** (Create React App)
- **react-three-fiber** (three.js renderer for React)
- **@react-three/drei** (helpers for three.js)
- **Axios** (API calls to backend)
- **CSS / basic animations**

## How the frontend works
1. User inputs a city name or manual weather values
2. Frontend sends request to the Flask backend
3. Backend returns rainfall predictions from both models
4. Frontend renders:
   - prediction values
   - model comparison
   - 3D rain / water visual effects
